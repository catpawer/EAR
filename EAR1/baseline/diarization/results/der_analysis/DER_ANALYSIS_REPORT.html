EAR-1 DiariZen 基线 DER 详细分析报告

对齐诊断修订： 本报告原始 DER 和下方错误分解均使用未经时间平移的参考标注。 进一步检查发现，开发集 R1 与 D1 音频在若干 session 有系统性时移。 尤其 20260923-1 的 R1 比 D1 晚约 2.03 秒，而两份 TextGrid 使用相同时间戳。 因此该 session 的 R1 46.92% 不能直接解释为模型性能。 仅平移参考时间 +2.03 秒、不改变模型输出的诊断 DER 为 20.93%。 这是对齐实验，不是组织方公布的正式修正分数。

1. 结论摘要

本次分析复现并逐项分解了开发集未经时间平移的严格 DER：D1 为 31.22%， R1 为 33.75%。R1 的部分错误包含参考与音频的时间轴不匹配； 其余原始错误还涉及以下问题：

  1. 原始分数中重叠语音错误占比较高。 重叠区贡献 D1 全部错误的 45.5%、R1 的 42.3%；重叠区自身 DER 约 47%。R1 数值需在对齐后重新评估。
  2. 部分 session 严重低估说话人数。 最典型的是 20260924-5：参考有 8 位说话人，D1 只输出 3 个聚类、R1 只输出 4 个聚类，多个次要说话人的覆盖率为 0%，直接产生大量漏检和说话人身份混淆。
  3. 短语音和密集边界很难。 0.5--1 秒语音段的目标说话人覆盖率只有 D1 54.7%、R1 48.6%，而大于等于 5 秒的语音段覆盖率达到 87.0% 和 85.7%。 将评分 collar 从 0 秒改为 0.25 秒后，D1/R1 DER 分别下降 7.01/6.53 个百分点。
  4. 原始评分中漏检最大。 漏检对总 DER 的贡献为 D1 16.53%、R1 19.56%。 R1 中有一部分漏检由时间轴不匹配造成，不能全部归因于 VAD 或通道噪声。
  5. 整段录音 UEM 会惩罚静音区误报。 静音区误报占全部错误约 15%。
  6. 20260923-1/R1 存在约 2.03 秒系统性时移。 开头和结尾的音频包络均 指向相同延迟；平移参考时间后的诊断 DER 从 46.92% 降至 20.93%。

应先核实并校正 R1 与参考标注的时间轴，再评估调整聚类阈值、加入重叠检测、 改善短语音和边界处理的效果。

2. 评分口径

  • 指标：pyannote.metrics.DiarizationErrorRate
  • Collar：0 秒
  • 重叠：保留并计分
  • UEM：从 0 秒到音频结尾的整段录音，包括静音区
  • 推理：没有使用 oracle VAD
  • 说话人映射：每个 session/track 使用一次全局 Hungarian 最优一一映射

本文统一使用以下中文名称，并在首次出现时保留 CSV/评分工具中的英文缩写：

  • 漏检（MISS）：参考中有人讲话，但系统少检出了说话人。
  • 误报（FA，False Alarm）：系统多报了说话人，包括静音时误报有人讲话，以及有 语音时多报说话人数。
  • 说话人身份混淆（CONF，Confusion）：检测到了讲话，但归属到了错误的说话人。

所有局部窗口、参考语音段和错误区间都固定使用同一套 session 全局映射。局部统计没有 重新优化说话人映射，因此不会人为隐藏 speaker confusion。

  • 预测说话人数正确，但重叠比例达到 22.5%。

9. 音频通道诊断

  • 所有 D1/R1 文件的削波样本比例均为 0%。
  • 绝对 RMS 与 DER 的 Pearson 相关系数约为 -0.33，不能支持“音量越低 DER 越高”这一 简单解释。
  • 20260924-2/D1 的整体 RMS 很低（-56.96 dBFS），但 DER 只有 16.90%，说明模型 并非仅因低增益失败。
  • 20260923-2/R1 比 D1 低约 8.6 dB，但 DER 反而稍低，也说明绝对增益不是主因。
  • 20260923-1/R1 以未经时间平移的参考标注计算出的语音与静音能量差为 1.00 dB。时间轴错位会把真实语音划进“参考静音”块，因此该值不能作为 R1 噪声严重或 VAD 崩溃的证据。

10. 可能原因与置信度

高置信度

  1. 说话人数估计不足/聚类阈值过保守。 20260924-5、20260908-2、 20260923-2/D1 有直接的 Ref/Hyp 数量和说话人覆盖证据。
  2. 重叠语音处理不足。 重叠区贡献 42%--46% 全部错误，多个零覆盖说话人的发言 高度集中在重叠区。
  3. 短语音和边界量化误差。 短 turn 覆盖率显著低，0.25 秒 collar 能降低约 6--7 个百分点。
  4. R1 时间轴不匹配。 20260923-1 的开头和结尾都测得约 2.03 秒延迟； 平移参考时间使该 session R1 DER 降低约 26 个百分点。

中等置信度

  1. 非 oracle VAD 漏检。 在先排除时间轴错位后，仍可能存在 VAD 漏检； 原始 R1 漏检秒数不能直接用来估计模型本身的 VAD 缺陷。
  2. 长尾说话人和类别不平衡。 主说话人通常覆盖较好，时长短、重叠多的次要说话人 容易没有独立聚类。
  3. 静音区过分割。 整段 UEM 下，静音区误报贡献约 15% 错误；20260923-5 的 错误尤其以误报和边界偏差为主。

较低置信度或尚未证实

  1. 单纯整体音量过低。 数据不支持它作为总体主因。
  2. 部分 R1 通道持续背景声/串音。 原先支持此判断的 20260923-1/R1 能量对比受时间错位污染，需要重新对齐后再分析。
  3. 模型/依赖版本差异。 它可能解释本次结果与 README 贡献者数字的少量差异，但 无法解释当前 session 内部已经观察到的具体漏检、误报和身份混淆模式。

11. 建议的验证实验顺序

  1. R1 时间轴核查：先核实每个 session 的通道同步方式，按确认的时间偏移 重评分；保留原始分数作为对照，不把诊断分数当作官方结果。
  2. Oracle speaker count 实验：对每个 session 固定参考说话人数，只重跑聚类。 如果 20260924-5 和 20260908-2 大幅下降，就能确认人数估计是主要瓶颈。
  3. Oracle VAD 实验：保持 embedding/聚类不变，仅用参考 speech regions。 它能定量分离 VAD 错误与 speaker clustering 错误。

12. 明细文件说明

  • sessions.csv：14 个 session-track 的总体分解、说话人数、四种评分条件。
  • time_windows.csv：每 60 秒的漏检、误报、身份混淆和 DER，共 360 行。
  • contexts.csv：静音、单人、重叠三种区域的误差分解。
  • reference_speakers.csv：每位参考说话人的时长、覆盖率、重叠比例、聚类碎片情况。
  • speaker_mappings.csv：预测聚类到参考说话人的全局映射与 purity。
  • speaker_cooccurrence.csv：所有预测/参考说话人组合的共现矩阵长表。
  • reference_turns.csv：每个参考语音段的目标覆盖率和区间内错误，共 8813 行。

  • error_regions.csv：所有连续错误区间，共 21666 行，可直接定位 WAV 时间戳。

reference_turns.csv 使用注意

target_coverage_pct 是该条参考说话人的独立覆盖率。interval_miss_s、 interval_fa_s、interval_conf_s 则是在该时间范围内对所有同时活跃说话人计算的标准 DER 分量。因此重叠语音段之间不能简单相加，否则会重复统计同一时间区间。
