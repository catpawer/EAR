## 1. 结论摘要

本次分析复现并逐项分解了开发集**未经时间平移**的严格 DER：D1 为 **31.22%**，
R1 为 **33.75%**。R1 的部分错误包含参考与音频的时间轴不匹配；
其余原始错误还涉及以下问题：

1. **原始分数中重叠语音错误占比较高。** 重叠区贡献 D1 全部错误的 45.5%、R1
   的 42.3%；重叠区自身 DER 约 47%。R1 数值需在对齐后重新评估。
2. **部分 session 严重低估说话人数。** 最典型的是 `20260924-5`：参考有 8
   位说话人，D1 只输出 3 个聚类、R1 只输出 4 个聚类，多个次要说话人的覆盖率为
   0%，直接产生大量漏检和说话人身份混淆。
3. **短语音和密集边界很难。** 0.5--1 秒语音段的目标说话人覆盖率只有 D1
   54.7%、R1 48.6%，而大于等于 5 秒的语音段覆盖率达到 87.0% 和 85.7%。
   将评分 collar 从 0 秒改为 0.25 秒后，D1/R1 DER 分别下降 7.01/6.53 个百分点。
4. **原始评分中漏检最大。** 漏检对总 DER 的贡献为 D1 16.53%、R1 19.56%。
   R1 中有一部分漏检由时间轴不匹配造成，不能全部归因于 VAD 或通道噪声。
5. **整段录音 UEM 会惩罚静音区误报。** 静音区误报占全部错误约 15%。
6. **`20260923-1/R1` 存在约 2.03 秒系统性时移。** 开头和结尾的音频包络均
   指向相同延迟；平移参考时间后的诊断 DER 从 46.92% 降至 20.93%。

应先核实并校正 R1 与参考标注的时间轴，再评估调整聚类阈值、加入重叠检测、
改善短语音和边界处理的效果。

## 2. 评分口径

- 指标：`pyannote.metrics.DiarizationErrorRate`
- Collar：0 秒
- 重叠：保留并计分
- UEM：从 0 秒到音频结尾的整段录音，包括静音区
- 推理：没有使用 oracle VAD
- 说话人映射：每个 session/track 使用一次全局 Hungarian 最优一一映射

本文统一使用以下中文名称，并在首次出现时保留 CSV/评分工具中的英文缩写：

- **漏检（MISS）**：参考中有人讲话，但系统少检出了说话人。
- **误报（FA，False Alarm）**：系统多报了说话人，包括静音时误报有人讲话，以及有
  语音时多报说话人数。
- **说话人身份混淆（CONF，Confusion）**：检测到了讲话，但归属到了错误的说话人。

所有局部窗口、参考语音段和错误区间都固定使用同一套 session 全局映射。局部统计没有
重新优化说话人映射，因此不会人为隐藏 speaker confusion。

## 3. 总体误差分解

| 轨道 | 参考说话人时间 | 漏检（MISS） | 误报（FA） | 身份混淆（CONF） | DER |
|---|---:|---:|---:|---:|---:|
| D1 | 10809.71 s | 1787.30 s / 16.53% | 641.34 s / 5.93% | 945.70 s / 8.75% | **31.22%** |
| R1 | 10799.99 s | 2112.58 s / 19.56% | 684.15 s / 6.33% | 847.94 s / 7.85% | **33.75%** |

R1 相比 D1：

- 漏检增加 325.28 秒；
- 误报增加 42.81 秒；
- 说话人身份混淆反而减少 97.76 秒；
- 净增约 270.3 秒错误。

原始分数里 R1 增加的主要是漏检，但时间轴错位会把正确预测转成漏检和误报，
不能据此认定 R1 模型的 VAD 一定更差。

## 4. Collar 与重叠语音的敏感性

| Track | 严格：0 collar + overlap | 跳过 overlap | 0.25 s collar | 0.25 s collar + 跳过 overlap |
|---|---:|---:|---:|---:|
| D1 | 31.22% | 24.42% | 24.21% | 17.80% |
| R1 | 33.75% | 27.91% | 27.22% | 21.63% |

解释：

- 只忽略重叠区域，D1/R1 分别下降 6.79/5.84 个百分点。
- 只使用 0.25 秒 collar，D1/R1 分别下降 7.01/6.53 个百分点。
- 两者同时使用后仍有 17.80%/21.63%；R1 残余错误中也可能包含尚未校正的时轴误差。
- 0.25 秒 collar 会从大量短语音边界周围移除相当多的参考时间，所以它是诊断指标，
  不能替代比赛规定的严格分数。

### Session 诊断

#### 20260908-1

- 预测说话人数正确，但重叠比例达到 22.5%。
- D1 的 P006/P009 覆盖率仅 49.3%/3.7%；R1 的 P006/P009 为 13.2%/51.9%。
- 说明次要说话人在重叠区被主说话人聚类吞并，而不是简单的聚类数量错误。

#### 20260908-2

- 参考 4 人，D1/R1 都只输出 3 个聚类。
- P009 有 181.6 秒参考语音，但两个轨道的独立目标覆盖率都为 0%；其 73.2% 时间
  位于重叠区。
- 这是典型的聚类不足（under-clustering），表现为较高漏检和说话人身份混淆。

#### 20260923-1

- D1 原始 DER 为 23.85%，R1 为 46.92%。D1/R1 音频包络在开头和结尾都显示
  R1 约晚 2.03 秒，但参考 TextGrid 未作相应平移。
- 仅把 R1 参考时间后移 2.03 秒的诊断 DER 为 20.93%，说明原始漏检和误报中有
  大量时间轴误差。该结果不是官方分数，也未改动模型输出。
- 原先用于推断持续背景声的 1.00 dB 语音/静音能量差受错位影响，不能作为噪声证据。
- R1 输出 5 个聚类而参考为 4 人；对齐后仍需单独分析聚类。

#### 20260923-2

- D1 只输出 3 个聚类；P031/P033 覆盖率分别只有 3.1%/0%，导致漏检达到 28.60%。
- R1 输出 4 个聚类；未平移评分的 DER 为 40.65%。音频包络显示 R1 相对 D1
  约早 0.54 秒，平移参考后的诊断 DER 为 26.15%，所以原始 VAD/误报归因不可靠。

#### 20260923-5

- 几乎没有重叠，预测人数正确，说话人身份混淆接近 0。
- 错误主要是边界/VAD：使用 0.25 秒 collar 后 D1/R1 从 14.89%/15.43% 降至
  8.41%/8.65%。
- 该 session 适合用于单独调 VAD 与边界平滑参数。

#### 20260924-2

- 参考和预测均为 7 个说话人，整体 DER 最低一档。
- P034 的 48.8 秒语音几乎全部位于重叠区，独立目标覆盖率为 0%；但其总时长较小，
  因此没有把整体 DER 大幅拉高。
- D1/R1 各有一个几乎不与参考说话人重合的额外聚类，说明仍存在少量噪声聚类。

#### 20260924-5

- 最严重的 session：参考 8 人，D1 只有 3 个聚类，R1 只有 4 个聚类。

## 9. 音频通道诊断

- 所有 D1/R1 文件的削波样本比例均为 0%。
- 绝对 RMS 与 DER 的 Pearson 相关系数约为 -0.33，不能支持“音量越低 DER 越高”这一
  简单解释。
- `20260924-2/D1` 的整体 RMS 很低（-56.96 dBFS），但 DER 只有 16.90%，说明模型
  并非仅因低增益失败。
- `20260923-2/R1` 比 D1 低约 8.6 dB，但 DER 反而稍低，也说明绝对增益不是主因。
- `20260923-1/R1` 以**未经时间平移的参考标注**计算出的语音与静音能量差为
  1.00 dB。时间轴错位会把真实语音划进“参考静音”块，因此该值不能作为
  R1 噪声严重或 VAD 崩溃的证据。

## 10. 可能原因与置信度

### 高置信度

1. **说话人数估计不足/聚类阈值过保守。** `20260924-5`、`20260908-2`、
   `20260923-2/D1` 有直接的 Ref/Hyp 数量和说话人覆盖证据。
2. **重叠语音处理不足。** 重叠区贡献 42%--46% 全部错误，多个零覆盖说话人的发言
   高度集中在重叠区。
3. **短语音和边界量化误差。** 短 turn 覆盖率显著低，0.25 秒 collar 能降低约 6--7
   个百分点。
4. **R1 时间轴不匹配。** 20260923-1 的开头和结尾都测得约 2.03 秒延迟；
   平移参考时间使该 session R1 DER 降低约 26 个百分点。

### 中等置信度

5. **非 oracle VAD 漏检。** 在先排除时间轴错位后，仍可能存在 VAD 漏检；
   原始 R1 漏检秒数不能直接用来估计模型本身的 VAD 缺陷。
6. **长尾说话人和类别不平衡。** 主说话人通常覆盖较好，时长短、重叠多的次要说话人
   容易没有独立聚类。
7. **静音区过分割。** 整段 UEM 下，静音区误报贡献约 15% 错误；`20260923-5` 的
   错误尤其以误报和边界偏差为主。

### 较低置信度或尚未证实

8. **单纯整体音量过低。** 数据不支持它作为总体主因。
9. **部分 R1 通道持续背景声/串音。** 原先支持此判断的
   `20260923-1/R1` 能量对比受时间错位污染，需要重新对齐后再分析。
10. **模型/依赖版本差异。** 它可能解释本次结果与 README 贡献者数字的少量差异，但
    无法解释当前 session 内部已经观察到的具体漏检、误报和身份混淆模式。

## 11. 建议的验证实验顺序

1. **R1 时间轴核查**：先核实每个 session 的通道同步方式，按确认的时间偏移
   重评分；保留原始分数作为对照，不把诊断分数当作官方结果。
2. **Oracle speaker count 实验**：对每个 session 固定参考说话人数，只重跑聚类。
   如果 `20260924-5` 和 `20260908-2` 大幅下降，就能确认人数估计是主要瓶颈。
3. **Oracle VAD 实验**：保持 embedding/聚类不变，仅用参考 speech regions。
   它能定量分离 VAD 错误与 speaker clustering 错误。
4. **重叠检测实验**：加入 overlap-aware segmentation，优先检查 `20260924-5`、
   `20260908-2` 和 P034/P039/P040/P042 等高重叠说话人。
5. **边界平滑/短段合并实验**：在 `20260923-5` 上调 VAD onset/offset、min-duration、
   padding；该 session 几乎没有聚类混淆，最适合隔离 VAD 效果。
6. **R1 降噪/VAD 实验**：完成时间对齐后，再针对剩余错误做频谱和回听，
   判断降噪或更稳健的 VAD 是否有帮助。
7. **逐窗口回听**：从本报告列出的最差一分钟开始，再使用 `error_regions.csv` 下钻到
   秒级区间；同时对照原始 WAV、参考 RTTM 和预测 RTTM。

## 12. 明细文件说明

- `sessions.csv`：14 个 session-track 的总体分解、说话人数、四种评分条件。
- `time_windows.csv`：每 60 秒的漏检、误报、身份混淆和 DER，共 360 行。
- `contexts.csv`：静音、单人、重叠三种区域的误差分解。
- `reference_speakers.csv`：每位参考说话人的时长、覆盖率、重叠比例、聚类碎片情况。
- `speaker_mappings.csv`：预测聚类到参考说话人的全局映射与 purity。
- `speaker_cooccurrence.csv`：所有预测/参考说话人组合的共现矩阵长表。
- `reference_turns.csv`：每个参考语音段的目标覆盖率和区间内错误，共 8813 行。
- `turn_duration_buckets.csv`：语音段时长桶的覆盖率统计。
- `error_regions.csv`：所有连续错误区间，共 21666 行，可直接定位 WAV 时间戳。
- `audio_diagnostics.csv`：每轨电平分位数、语音/静音能量差和削波比例。
- `metadata.json`：输入路径、评分政策、窗口长度和各文件行数。

### `reference_turns.csv` 使用注意

`target_coverage_pct` 是该条参考说话人的独立覆盖率。`interval_miss_s`、
`interval_fa_s`、`interval_conf_s` 则是在该时间范围内对所有同时活跃说话人计算的标准
DER 分量。因此重叠语音段之间不能简单相加，否则会重复统计同一时间区间。
